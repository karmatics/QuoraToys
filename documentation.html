1. Forensic Self-Assessment & Technical Debt Record

Identified Implementation Defects & Corrective Resolutions:

  • Radian vs. Degree Mismatch: GeometryUtils.rotateVector(v, angleRad) evaluates in radians. Early code fed degree values (e.g. 45°), causing the tangent vector to spin by over 7 full revolutions ($2578^\circ$) and flip directions. Resolved: Tangent angle offsets are strictly kept in radians ($\Delta\theta \in [-\pi, \pi]$).
  • Viewport Clipping of Floating Palettes: Mounting floating toolbars inside transformed article containers resulted in edge clipping. Resolved: HUD palettes and debug dialogs mount directly to document.body with fixed coordinates.
  • Canonical ColorPicker Substitution: Stubbed canvas methods temporarily replaced the original ColorPicker. Resolved: Restored untouched Library/ColorPicker.js with canonical HueRingCP.js, TriangleCP.js, and AppColorUtils.js.
  • Straight-Line Degradation: Secondary straight-line routines generated degenerate loops ("backwards zeros"). Resolved: Purged straight-line tool. All lines are natural splines whose intermediate knots can be straightened dynamically.
  • Label Padding & Framing: Standard SVG rects caused trailing whitespace gaps. Resolved: Reduced character metric overhang and introduced 2-sided architectural bracket frames (bottom shelf + entrance wall).

2. Mathematical Formulations & Algorithmic Foundations

A. The Kinetic String-Tether (Virtual Drag-Lead)

To eliminate high-frequency hand tremors, the pen tip is pulled by a virtual string of radius $R$ ($32\text{px}$):

If dist(Cursor, Pen) < R:
    Pen stays stationary at P_last
Else:
    U = (Cursor - P_last) / dist(Cursor, P_last)
    Pen = Cursor - U * R

B. Inverse Knot Parameter Derivation

Schneider's curve fitter outputs cubic Bézier segments $[P_0, P_1, P_2, P_3]$. The studio translates these into canonical BezierVertex knots without fixed tangents:

1. Knot Position: V_i = P_0, V_{i+1} = P_3
2. Actual Drawn Tangent: T_actual = normalize(P_1^{(i)} - P_2^{(i-1)})
3. Natural Relaxation Baseline: T_base = normalize((V_{i+1} - V_i)/D_next + (V_i - V_{i-1})/D_prev)
4. Signed Angle Offset (Radians):
   theta = atan2(T_base.x * T_actual.y - T_base.y * T_actual.x, T_base.x * T_actual.x + T_base.y * T_actual.y)
5. Scale & Balance:
   S_out = 3 * ||P_1 - V_i|| / D_next
   S_in  = 3 * ||V_i - P_2|| / D_prev
   Curvature C = (S_out + S_in) / 2
   Balance   B = (2 * S_in) / (S_out + S_in)

C. Hand-Drawn Concave Arrowhead Geometry

Anchored at $P_0$ (initial touch point), barbs extend backward along the exit tangent and bow concavely toward the stem:

Stem Tangent: U = normalize(Curve(0.25) - P_0), Normal N = (-U.y, U.x)
Barb Ends:    B_1 = P_0 + U*18 + N*11,  B_2 = P_0 + U*18 - N*11
Bowed Ctrls:  C_1 = P_0 + U*8 + N*2,    C_2 = P_0 + U*8 - N*2
SVG Path:     M B_1 Q C_1 P_0 M P_0 Q C_2 B_2
