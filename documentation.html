QuoraToys & Studio: Living Architecture & Iteration Plan

Version 2.9.3 • Living Engineering Specification

Core Purpose: Universal Graphic Studio for fast visual commentary. Combines kinetic drawstring curve smoothing, legible glowing callouts, subtle inline editing, explicit UI controls, and clean custom-bounded retina exports.

1. Explicit Interface & Portable Settings Plan

  • Zero Opaque Toggles: Segmented selectors display all options directly (Style: Ink | Neon, Arrow: Off | Tip | Tail | Both, A- / px / A+).
  • Clipboard Settings Capture: In ✨ Style & Settings, 📋 Copy Settings exports the active JSON defaults to clipboard and 📥 Paste restores or shares presets immediately.

2. Subtle Pale-Box Text Flow & Readability Glow

  • Seamless Click-to-Type: Clicking a curve body (without dragging) or its compact pale Note… box focuses inline text immediately; metrics match the SVG output so wrapping remains consistent.
  • Command Mode Escape: Pressing Escape commits text and returns to Curve Command Mode; Arrow keys nudge the active item and Alt+Arrow cycles focus across knots and annotations.
  • Readability-First Glow: Separate controls for Text Glow Mode (Neon | Halo | Shadow | None), Dark Outline Halo, Glow Blur, Glow Spread, Glow Opacity, Core Saturation, and Backdrop Opacity prevent fuzzy illegible text.

3. Custom Export Boundary Rectangle & Clean Export

  • Tight Auto-Bounds vs. Custom Export Area: Exports tightly wrap content by default, or use 📐 Export Area to drag and resize an explicit crop boundary with one-click ✕ Auto reset.
  • Full Glow Preservation: Export clones the SVG with explicit xmlns, width, height, and viewBox while preserving glowLayer and supporting both Matte and Transparent PNG output.

4. Tether Backup-Erase & Slack-String Cusp Plan

  • Restored Contiguous Backup & Erase (Implemented): During drawstring drawing, a dashed cursor circle (#qa-cursor-erase-circle, radius clamp(eraseRadius, 8, 0.62 * tetherLength)) visualizes the active erase zone. Backing the cursor over the active tip (including fast sweeps via segment distance) contiguously rewinds trailing strokePoints from the tip without disturbing earlier crossed loops, while showing dashed slack-tether feedback between the erase boundary and the full tether radius.
  • Stage 1 — Slack-State & Incoming Tangent Memory: In QuoraGestureMachine, record the incoming unit draw direction d_in whenever the cursor enters the slack zone (eraseR < dist < tetherLen) or completes an erase rewind.
  • Stage 2 — Direction Reversal Detection & Live Telegraph: As the user pulls taut again in direction d_out, compute turn angle theta = acos(dot(d_in, d_out)). When theta >= cuspAngleThreshold (e.g., 45°–55°), mark the current tip index in cuspIndices and preview an amber diamond cusp marker at curTip while slack.
  • Stage 3 — Piecewise Cusp-Segmented Fitting: Split strokePoints at each index in cuspIndices before calling CurveFitter.fit(), fitting each smooth sub-chain independently so the corner vertex is preserved identically and adjacent Bézier control points remain non-collinear.
  • Stage 4 — Persistent Cusp State Until Straightened: Flag the boundary BezierVertex with isCusp = true and retain independent incoming/outgoing tangent offsets in UpdateControlPoints across neighbor drags until explicitly straightened via the C hotkey or knot context menu.
